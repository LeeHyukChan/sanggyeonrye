# 상견례 모바일 리플릿 기획안

## 1. 목적

- 처음 만나는 양가 부모님의 어색함을 줄이고, 자연스럽게 대화가 이어지도록 돕는다.
- 테이블에 놓인 QR을 찍으면 휴대폰에서 바로 열린다. 앱 설치·로그인 없음.
- 종이 3단 리플릿(Claude 디자인 캔버스에서 제작)과 같은 내용을 웹으로도 제공한다.

## 2. 대상과 사용 환경

| 항목 | 내용 |
|---|---|
| 주 사용자 | 양가 부모님 (50~60대) |
| 기기 | 휴대폰 세로 화면 (카카오톡/카메라 QR 스캔 → 기본 브라우저) |
| 상황 | 별실 식당, 식사 전 대기 시간·디저트 시간 |
| 사용 시간 | 3~5분 훑어보기 |

## 3. 화면 구성 (위 → 아래)

종이 리플릿의 면 순서를 휴대폰 한 줄 스크롤로 풀었다. 메뉴를 리플릿 맨 왼쪽 면에 두기로 했기 때문에
웹에서도 표지 바로 다음, 가장 먼저 보이는 자리에 놓았다.

| # | 섹션 | 내용 | 리플릿 위치 |
|---|---|---|---|
| 1 | 표지 | 아치형 커플 사진, 두 사람 이름, 날짜 | 바깥면 오른쪽 (앞표지) |
| – | 바로가기 | 메뉴 / 순서 / 소개 / 예식 / 가족 버튼 | – |
| 2 | **오늘의 메뉴** | 설담(SeolDam) A코스 8가지 | **맨 왼쪽 면** |
| 3 | 오늘의 약속 | 분위기를 푸는 세 가지 약속 | 바깥면 왼쪽 날개 |
| 4 | 오늘의 순서 | 진행 순서 4단계 + 일시·장소 | 바깥면 가운데 (뒷표지) |
| 5 | 저희를 소개합니다 | 서로가 소개하는 신랑·신부 | 안쪽면 왼쪽 |
| 6 | 예식 안내 | 식장 사진, 일시·장소·주소, 카카오맵 길찾기 | 안쪽면 가운데 |
| 7 | 두 가족 · 앞으로의 우리 | 양가 가족, 예식 시기·신혼집 지역·꿈 | 안쪽면 오른쪽 |
| 8 | 마무리 인사 | 감사 인사와 서명 | – |

### 오늘의 메뉴 (설담 A코스)

타락죽 → 전 → 한우 안심 편채 → 세 가지 한입 요리 → 계절 국수 → 한우 구이 → 반상 → 샤베트

- 가격, 중량(90g/120g/150g), 추가 옵션(부위 변경, 트러플 추가 등)은 **일부러 넣지 않았다.**
  부모님께 보여드리는 자리이므로 금액이 드러나지 않게 했다.
- 당일 실제 중량이나 변경 옵션을 고르면 `한우 구이` 아래 설명 한 줄로 덧붙일 수 있다.

## 4. 콘텐츠 원칙

- **넣는 것**: 사진, 서로를 칭찬하는 한 줄, 연애 에피소드, 예식 시기와 신혼집 지역 정도
- **빼는 것**: 비용·예물·예단, 학력·연봉 같은 스펙, 구체적인 집값이나 조건
- 가족 소개는 아버지 → 어머니 → 형제 순서로
- 양가 분량을 똑같이 맞춘다

## 5. 디자인

| 항목 | 결정 |
|---|---|
| 톤 | 단정하고 따뜻한 한지 느낌. 화려한 장식 없음 |
| 색 | 바탕 아이보리 `#F6F4EE`, 글자 `#2B2B28`, 포인트 세이지그린 `#4F6B55` |
| 서체 | 제목: 고운바탕(명조), 본문: Noto Sans KR |
| 글자 크기 | 본문 17px 이상, 제목 30px. 부모님 시력을 고려해 크게 |
| 버튼 | 손가락으로 누르기 쉽게 높이 44px 이상 |
| 레이아웃 | 최대 너비 480px 한 줄. PC로 열어도 휴대폰 화면처럼 가운데 정렬 |

## 6. 기술 구성

- 정적 HTML 한 파일 (`index.html`), 별도 빌드나 서버 없음
- 호스팅: GitHub Pages (`main` 브랜치 루트)
- 외부 의존성: Google Fonts만 사용
- 사진이 없으면 회색 자리 표시가 보이게 처리 → 사진을 늦게 넣어도 화면이 깨지지 않음
- `noindex` 메타태그로 검색엔진 노출 차단
